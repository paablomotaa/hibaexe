# Hiba's Birthday ♡

Mini web de cumpleaños para Hiba, hecha con HTML, CSS y JavaScript vanilla.

## Cómo abrirla
1. Descarga y descomprime `hibas_cumple.zip`.
2. Abre la carpeta `hibas_cumple`.
3. Haz doble clic en `index.html` para verla en el navegador.

No necesita instalar nada ni usar servidor.

## Personalizarla
- **Textos y secciones:** edita `index.html`.
- **Colores, diseño y responsive:** edita `css/styles.css`. Los colores principales están al principio en `:root`.
- **Regalos, mensajes de Luna, confeti y modo brainrot:** edita `js/script.js`.
- **Canción:** el regalo musical abre una búsqueda de “Masterpiece” de Motionless In White en Spotify. No se reproduce automáticamente.

## Publicarla gratis
Puedes subir los archivos a GitHub y activar GitHub Pages desde Settings → Pages. Sube `index.html`, `css/` y `js/` manteniendo la estructura de carpetas.
